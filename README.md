# Hello World Multi-Language Repository

## Description

This repository contains beginner-level "Hello, World!" programs in C, C++, Python, and Java.

## Project Structure

```text
.
├── hello.c
├── hello.cpp
├── hello.py
├── Hello.java
└── README.md
```

## Usage / Execution Guide

### C

```sh
gcc hello.c -o hello
./hello
```

### C++

```sh
g++ hello.cpp -o hello_cpp
./hello_cpp
```

### Python

```sh
python3 hello.py
```

### Java

```sh
javac Hello.java
java Hello
```
